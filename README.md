# Employee Management System

A full-stack Employee Management System built using ASP.NET Core Web API, React, Entity Framework Core, and SQL Server.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Role-Based Authorization
- Employee CRUD Operations
- Department CRUD Operations
- Department Dropdown
- Employee Search
- Pagination
- Input Validation
- Loading & Error Handling
- Swagger API Documentation
- SQL Server Database
- Entity Framework Core

## 🛠️ Technologies Used

### Backend
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- Swagger

### Frontend
- React
- JavaScript
- Axios
- HTML
- CSS

## 🔐 Authentication

The application uses JWT Bearer Authentication.

Users can:
- Register
- Login
- Access protected APIs using JWT tokens
- Access Admin-only Department APIs based on their role

## 👨‍💼 Employee Management

The system supports:

- Add Employee
- View Employees
- View Employee by ID
- Edit Employee
- Delete Employee
- Search Employees
- Pagination

## 🏢 Department Management

The system supports:

- Add Department
- View Departments
- Edit Department
- Update Department
- Delete Department

## 🗄️ Database

SQL Server is used as the database and Entity Framework Core is used for database access.

Main entities:

- Employee
- Department
- User
